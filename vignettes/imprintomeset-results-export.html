imprintomeR Team

Overview

This vignette demonstrates the full visualization and export workflow after completing imprinting analysis with runImprintome().

Visualization in imprintomeR follows the preprocessing-first architecture:

  1. MethQcSet: QC preprocessing (see ImprintomeSet Workflow Quickstart)
  2. ImprintomeSet: Analysis-ready container for imprinting studies (this vignette)
  3. Results & Plots: Stored in results(x) and plots(x) slots

The examples below are organized by visualization level:

  • sample-level (polar, radar, rainfall)
  • probe-level (beeswarm, violin, mirror density)
  • cohort-level (heatmap, cor_heatmap, circular_heatmap)
  • chromosome-level (beeswarm_chr)

For object construction and QC preprocessing, see ImprintomeSet Workflow Quickstart.

1. Start from a QC-Approved ImprintomeSet Object

Your ImprintomeSet object x should come from either:

Option A: QC-preprocessed data via MethQcSet

# Load metadata: tab-delimited with at least Sample_Name and Sample_Group.
# For QC workflow (raw IDAT files): also include Basename column (IDAT path prefixes).
# For direct analysis (QC already done): Basename is not needed.
meta <- LoadMeta("meta.tsv")

# Option A1: platform unknown — detect first
meta <- check_platform(meta)
meta_epic <- meta[meta$Platform == "EPIC", ]
qcset <- runMethQC(meta_epic)  # platform auto-resolved from meta$Platform

# Option A2: platform known — pass directly
# qcset <- runMethQC(meta, platform = "EPIC")

export(qcset, outdir = "qc_output", format = c("xlsx", "rds"))
# xlsx: single workbook with sheets — meta (+ Platform, Final.QC),
#   QC_matrix, recall_rate, cutoffs, ctrl_metrics, contamination,
#   predUniqDonor_ID. Beta saved as .rds only.

# QC visualizations
p_bar  <- plot(qcset, type = "qc_bar")                          # PASS/FAIL bar
p_int  <- plot(qcset, type = "intensity",  icutoff = 11)        # intensity scatter
p_dp   <- plot(qcset, type = "detection_pval", pcutoff = 0.05)  # avg det p-val
p_cov  <- plot(qcset, type = "probe_coverage")                  # % probes detected
p_sex  <- plot(qcset, type = "predicted_sex")                   # predicted sex
p_ctrl <- plot(qcset, type = "ctrl_metrics")                    # ewastools (if present)
plot(qcset, type = "ctrl_metrics_detail",                       # per-metric detail PDFs
     outFile = "qc_ctrl_metrics_detail")

# EPICv2 only: aggregate replicate probes before conversion (required step)
# as.ImprintomeSet() will error if this is skipped for EPICv2 data.
if (qcset@platform == "EPICv2") {
  qcset <- aggregate_probes(qcset)
}

# Convert the QC-clean MethQcSet to ImprintomeSet
probesets <- readRDS(system.file("extdata", "probesets_hg19.rds", package = "imprintomeR"))
x <- as.ImprintomeSet(
  qcset,
  probeset = probesets[["selected"]],
  genome = "hg19"
)

Option B: Pre-cleaned data loaded directly

# If you already have QC-cleaned data, skip MethQcSet
# Note: Basename column is not needed since QC step is skipped.
meta <- LoadMeta("meta.tsv")  # Only needs Sample_Name and Sample_Group
beta <- LoadBeta("cleaned_beta.tsv")

x <- ImprintomeSet(
  beta = beta,
  meta = meta,
  probeset = probesets[["selected"]],
  genome = "hg19",
  assay = "EPICv1"
)

Then run analysis on your analysis-ready ImprintomeSet:

library(imprintomeR)

# x is a valid ImprintomeSet object (QC-approved data)

# Run analysis on one or more probesets
x <- runImprintome(x, probeset = "selected", ids_cutoff = 0.2)
x <- runImprintome(x, probeset = "classifier3", ids_cutoff = 0.2,
                   result_name = "AnalyzeImprintStatus.classifier3")

names(results(x))

Extract slots once for plotting convenience:

beta_x <- beta(x)
meta_x <- meta(x)
res_x <- results(x)[["AnalyzeImprintStatus.selected"]]

2. Generic S4 Plot Method

The S4 plot() method supports explicit backend dispatch via plot_type.

Available plot_type values are:

  • auto
  • polar
  • mirror_density
  • beeswarm
  • beeswarm_origin
  • beeswarm_chr
  • violin
  • heatmap
  • circular_heatmap
  • cor_heatmap
  • rainfall
  • radar

2.1 Auto Dispatch

auto first returns the latest stored plot from plots(x) when present; otherwise, it falls back to polar plotting from IDS/Angle results.

5.3 Circular Heatmap

Circular heatmap displays methylation values arranged in a circular layout. Each chromosome forms a radial sector, with probes arranged clockwise. Sample groups are rendered as separate "pie slices" around the center white circle, allowing visual comparison of methylation patterns across grouped samples and chromosomes simultaneously.

Parameters:

  • sectionColumn: metadata column for grouping samples (default "Sample_Group"). If the column is missing, samples are grouped by Sample_Name (one section per sample). If both are missing, all samples appear in one section.
  • probeset: probeset name (default "selected")
  • SAMPLEID: metadata column for sample labeling

Features:

  • Shows probes × samples with chromosome organization
  • Color scale: blue (unmethylated, β ≈ 0) → white (hemimethylated, β ≈ 0.5) → red (methylated, β ≈ 1)
  • Automatic adaptive sizing: larger canvas (12×10 inches) accommodates 4+ sample groups
  • Section labels positioned in the inner white circle for clarity
# Group by sample group
plot(
  x,
  plot_type = "circular_heatmap",
  SAMPLEID = "SAMPLE_NAME",
  sectionColumn = "SAMPLE_GROUP",
  probeset = "selected",
  outFile = "beta_circular_heatmap.pdf"
)

# Alternatively, group by individual sample (one section per sample)
plot(
  x,
  plot_type = "circular_heatmap",
  SAMPLEID = "SAMPLE_NAME",
  sectionColumn = "SAMPLE_NAME",
  probeset = "selected",
  outFile = "beta_circular_heatmap_by_sample.pdf"
)

5.4 Heatmap Aggregated by Gene Symbol

This visualization aggregates probe-level beta values to gene-level summaries by grouping probes with the same Closest_TSS_gene_name from the selected probeset. Within each gene, probes are aggregated per sample using the median function.

Features:

  • Shows gene symbols as rows and samples as columns
  • Robust aggregation: reduces ~865k probes (EPICv2) → ~50-200 unique genes per probeset
  • Clustered by default: genes clustered via Euclidean distance (Ward linkage)
  • Top annotation: sample groups with automatic color assignment
  • Color scale: blue (unmethylated) → white (hemimethylated) → red (methylated)

Parameters:

  • probeset: probeset name (default "selected")
  • SAMPLEID: metadata column for sample labels
  • annoColumn: annotation column for top heatmap header (default "Sample_Group")
  • clusterRows: hierarchical cluster genes? (default TRUE)
  • clusterColumns: hierarchical cluster samples? (default TRUE)
  • outFile: output PDF file path
plot(
  x,
  plot_type = "heatmap_by_gene",
  probeset = "selected",
  SAMPLEID = "SAMPLE_NAME",
  annoColumn = "SAMPLE_GROUP",
  clusterRows = TRUE,
  clusterColumns = TRUE,
  outFile = "beta_heatmap_by_gene.pdf"
)

Alternatively, using the backend function directly:

hm <- BetaHeatmapByGene(
  beta = beta(x),
  meta = meta(x),
  probeset = "selected",
  SAMPLEID = "SAMPLE_NAME",
  annoColumn = "SAMPLE_GROUP",
  clusterRows = TRUE,
  clusterColumns = TRUE,
  outFile = "beta_heatmap_by_gene_direct.pdf"
)

9. Notes

  • Several plotting functions write side-effect files and also return plot objects.
  • For large cohorts, disable per-sample side folders where optional (pdfFolder = NULL).
  • Keep SAMPLE_NAME alignment between beta(x) and meta(x).
  • Advanced, non-dispatch plots can still be called directly when needed.
