# Real-World Imprinting Analysis: GSE52576 Dataset

*Download, preprocess, and analyze methylation data from a public GEO dataset*


## Overview

This vignette demonstrates imprintomeR on **GSE52576**, a real-world methylation dataset from the Gene Expression Omnibus (GEO). You will:

1. **Download** normalized beta values from GEO using GEOquery
2. **Create** an ImprintomeSet analysis-ready object
3. **Analyze** imprinting status across samples
4. **Visualize** results with all available plot types
5. **Interpret** biological patterns and aberrant imprinting
6. **Compare** scoring options: DMR type, bootstrap intervals, ICR-balanced and per-ICR scores, and locus panels

The workflow is optimized for **reproducibility** and **Jupyter notebook conversion**.

### Download GSE52576 from GEO

GSE52576 is a publicly available dataset of	Genome-wide parent-of-origin DNA methylation analysis using Illumina 450K methylation arrays.

```r

geo_gse <- "GSE52576"
```

## Phase 6: Scoring Options

The sections above use the package defaults: the `selected` panel scored on gametic ICRs against the fixed 0.5 reference. This phase shows the other scoring options on the same data. Each call adds a result table to `results(x)` under its own name, so earlier results are kept.

GSE52576 has no tissue-matched control group, so all scores here use the fixed 0.5 reference.

### Gametic ICRs, all probes and secondary DMRs

`runImprintome()` scores the core `selected` panel on gametic ICRs by default (`dmr_type = "gametic"`). `dmr_type = "all"` scores every probe, as in earlier package versions, and `dmr_type = "secondary"` scores the secondary DMRs separately.

```r
x <- runImprintome(x, probeset = "selected", dmr_type = "all")
x <- runImprintome(x, probeset = "selected", dmr_type = "secondary")
res <- results(x)

scored <- c(gametic    = "AnalyzeImprintStatus.selected",
            all_probes = "AnalyzeImprintStatus.selected.all",
            secondary  = "AnalyzeImprintStatus.selected.secondary")

# Probes per parental class for each selection
t(sapply(scored, function(nm) unlist(res[[nm]][1, c("n_paternal_probes", "n_maternal_probes")])))

# Mechanism of each sample under each selection
mechanism_by_selection <- data.frame(
  Sample_Name  = status$Sample_Name,
  Sample_Group = status$Sample_Group,
  sapply(scored, function(nm) res[[nm]]$Mechanism[match(status$Sample_Name, res[[nm]]$Sample_Name)])
)
mechanism_by_selection[order(mechanism_by_selection$Sample_Group), ]
```

The gametic paternal class is essentially the H19/IGF2 IG-DMR, so report `n_paternal_probes` alongside gametic scores.

### Bootstrap confidence intervals

`n_boot` adds percentile intervals for IDS and Angle from a two-stage bootstrap (ICRs, then probes within ICRs), and `Mechanism_support`, the fraction of replicates that fall in the reported sector. Use at least 1,000 replicates for reporting; 200 keep this example fast.

```r
x <- runImprintome(x, probeset = "selected", n_boot = 200, seed = 2026,
                   result_name = "AnalyzeImprintStatus.selected.boot")
boot <- results(x)[["AnalyzeImprintStatus.selected.boot"]]
boot[, c("Sample_Name", "Sample_Group", "IDS", "IDS_lower", "IDS_upper",
         "Angle", "Angle_lower", "Angle_upper", "Mechanism", "Mechanism_support")]
```

The intervals are conditional on the reference. The origin permutation test (`n_perm`) is interpretable only for scores centred on control samples (`reference_group`), and `CalibrateIDS()` needs tissue-matched controls, so neither is shown here.

### ICR-balanced IDS and per-ICR calls

The sample-level IDS pools all probes of a parental class, so probe-rich ICRs dominate it. `balance = "icr"` takes the median within each ICR and then across ICRs, so that each ICR counts once. `icr = TRUE` also scores each ICR on its own and summarizes the altered ICRs per sample.

```r
x <- runImprintome(x, probeset = "selected", balance = "icr", icr = TRUE)
res <- results(x)

# Probe-pooled versus ICR-balanced IDS
balanced <- res[["AnalyzeImprintStatus.selected.icr"]]
data.frame(Sample_Name      = status$Sample_Name,
           Sample_Group     = status$Sample_Group,
           IDS_pooled       = status$IDS,
           IDS_icr_balanced = balanced$IDS[match(status$Sample_Name, balanced$Sample_Name)])

# Per-ICR table (one row per sample and ICR) and per-sample summary
icr_table   <- res[["ICRStatus.selected"]]
icr_summary <- res[["ICRSummary.selected"]]
table(icr_table$DMR_type[!duplicated(icr_table$ICR_name)])   # ICRs scored, by DMR type
icr_summary[, c("Sample_Name", "Sample_Group", "n_icrs", "n_altered", "n_gain", "n_loss",
                "n_altered_chromosomes", "MLID")]

# Count gametic ICRs only
SummarizeICRStatus(icr_table, dmr_type = "gametic")[, c("Sample_Name", "n_icrs", "n_altered", "MLID")]
```

Per-ICR calls cover all annotated ICRs, secondary DMRs included. The call thresholds (|deviation| ≥ 0.075 and |z| ≥ 3) were validated with control samples. GSE52576 has normal tissues but no control group matched to the other samples' tissue. Without controls, `z` is unavailable and only the deviation criterion applies, so tissue-specific methylation is called altered. Note how many ICRs are called altered in samples expected to be normal. Treat these calls as exploratory, or rerun with controls from the same study (`reference_group`), or with a larger `delta_cutoff` such as 0.15.

### Locus panels: chr11p15 and chr20q13 (GNAS)

Locus panels give a two-axis IDS/Angle for a single imprinted domain: IC1 and IC2 at 11p15.5 (`chr11p15`), and GNAS-NESP against the maternal GNAS DMRs at 20q13 (`chr20q13`).

```r
x <- runImprintome(x, probeset = "chr11p15")
x <- runImprintome(x, probeset = "chr20q13")
res <- results(x)

do.call(rbind, lapply(c("chr11p15", "chr20q13"), function(p) {
  res[[paste0("AnalyzeImprintStatus.", p)]] %>%
    group_by(Sample_Group) %>%
    summarise(panel = p, n = n(), median_IDS = round(median(IDS), 3), max_IDS = round(max(IDS), 3),
              .groups = "drop")
}))
```

## Jupyter Notebook Conversion Guide

This guide is plain Markdown; each R code block is one notebook cell. To create a notebook with an R kernel:

```bash
jupytext --to notebook --set-kernel ir vignettes/GSE52576.md
```

**Tips for Jupyter users:**
- Run the raw-IDAT download and QC cells only when you need full preprocessing; they download a large archive.
- Save the downloaded GEO and IDAT files once and reuse them, rather than downloading in every session.
- Set `outFile` in plot calls to save publication-ready PDFs or PNGs.
- End with `local({ si <- sessionInfo(); si$BLAS <- basename(si$BLAS); si$LAPACK <- basename(si$LAPACK); si })` so that saved notebooks do not record local library paths.
